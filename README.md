# STALCRAFT Trade Assistant v2

Читает окно обмена STALCRAFT: X, считает количество каждого предмета, берёт цены из вашего
прайс-листа и показывает итог. **Только анализ экрана** — ничего не нажимает, не принимает и не
отправляет обмен, данные не уходят в сеть. Исходный проект не тронут: это отдельная папка.

## Установка (Windows)
1. Установите Python 3.11+ и Tesseract OCR с языками **eng** и **rus**
   (по умолчанию ожидается `C:\Program Files\Tesseract-OCR\tesseract.exe`; путь меняется в ☰ → Настройки).
2. Двойной клик по `run.bat` (создаст `.venv`, поставит зависимости, запустит) или:
   `py -3 -m venv .venv && .venv\Scripts\pip install -r requirements.txt && .venv\Scripts\python main.py`
3. Сборка EXE: `build_exe.bat` → `dist\STALCRAFT_Trade_Assistant\`.
4. Тесты: `.venv\Scripts\python -m pytest -q`

## Первый запуск
1. **☰ → Прайс-лист** — задайте цену за штуку каждому предмету (пока цены нет, предмет в сумму не входит).
2. **Область ▾ → Правая** — выделите сетку предметов, которые даёт партнёр (нижняя сетка, 8 колонок).
   Можно с небольшим запасом, но без заголовка с ником.
3. **Область ▾ → Левая** — выделите текст «Вы получите: …» слева от окна обмена (рекомендуется:
   это второй независимый источник количества).
4. Кнопка **«Скопировать сумму»** кладёт в буфер только число (например `141100`).

## Как это работает
* **Иконка** (OpenCV: цвет + форма + внешний вид, не зависит от масштаба) определяет предмет.
* **Количество `Nx`** на карточке читается отдельно (Tesseract, голосование по нескольким бинаризациям,
  быстрый проход → расширенный только для проблемных карточек). Подставлять «1» вместо нечитаемого числа нельзя.
* **Подтверждение**: количество принимается только если совпало со **списком слева** (`Название x N`)
  и/или с **весом стопки** (`105 г` = 7 × 15 г). Названия в списке сопоставляются строго.
* Статусы: ✔ уверенно (в сумме) · ⚠ требуется проверка (не в сумме) · ✖ не распознано (не в сумме).
  Наведите курсор — увидите причину. Двойной клик по ⚠ принимает позицию вручную (✎), если известны
  предмет, количество и цена. Если есть исключённые позиции, при копировании будет предупреждение.
* Скан каждые ~400 мс в фоновом потоке; если кадр не менялся — распознавание не запускается;
  карточки кэшируются. После «Сброс» результаты старых сканов игнорируются.
* ☰ → **Диагностика**: кадр с разметкой, карточки, OCR-тексты, оценки, причины; кнопка
  «Сохранить проблемный кадр» пишет всё в `data/problems/` для дообучения базы.
* ☰ → **Эталонные иконки**: добавить несколько вариантов иконки прямо из текущего трейда.

## Данные
`data/items.sqlite3` (предметы, цены, алиасы), `data/icons/` (эталоны), `data/config.json`, `data/app.log`.

## Что проверено, а что нет
Проверено (Linux-песочница, 27 автотестов) на **одном реальном скриншоте 1920×1080** и его
искусственных вариациях: масштаб 0.75–1.5, размытие, яркость, смещение области, пустой трейд,
стёртое количество, расхождение со списком, неизвестная иконка, предмет без цены.
**Не проверено:** запуск на Windows и в самой игре; сборка EXE; цифры 3, 4, 5, 8, 9 и числа ≥ 100
в реальном шрифте игры; вид заголовка «Вы отдадите…», когда вы тоже кладёте предметы;
прокрутка сетки партнёра (при расхождении со списком позиция уйдёт в ⚠); несколько мониторов
(выбор области работает на основном мониторе); вес в кг у больших стопок (такое чтение игнорируется).
Цвета иконок сопоставлены с названиями по совпадению количеств на скриншоте — проверьте в
☰ → Эталонные иконки.
